# 🏗️ Module 1 — Introduction au Data Engineering

**🚦 Statut : ![TERMINÉ](https://img.shields.io/badge/-TERMIN%C3%89-success)**
**Logique de ce module : compréhension uniquement** — pas de dockerisation ici, l'objectif était de poser les bases (vocabulaire, historique, rôle du métier, panorama des outils). Le rendu, c'est un mini-rapport/résumé exploitable en entretien.

## 🎯 Objectifs officiels du programme

- Définir la notion de data engineering
- Connaître l'historique du data engineering
- Comprendre les missions et les compétences clés du data engineer
- Explorer les domaines d'application du data engineering
- Découvrir les outils d'ETL (Extract, Transform, Load)
- Connaître les grandes catégories d'outils utilisés au quotidien par un data engineer

## 📚 Séquences

| Séquence | Contenu | Durée |
|---|---|---|
| Séquence 1 | Introduction au data engineering (définition, Big Data, 5V, métiers de la data, ETL) | 2h |
| Séquence 2 | Découverte des outils Data Engineering (stockage, traitement, visualisation, automatisation/déploiement) | 4h |

## 🧠 Ce que je retiens (en une phrase)

Le data engineer construit et fiabilise la tuyauterie qui rend la donnée exploitable pour tous les autres métiers de la data — sans lui, pas de data science, pas de BI fiable.
